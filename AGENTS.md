# Project instructions

When starting work in this folder in a new conversation or session, begin the
first response with this exact sentence: **I would continue in this conversation.**
Then read [PROJECT_CONTEXT.md](PROJECT_CONTEXT.md) and inspect the current files
before changing anything. Use the existing conversation context when available
and continue from it.

Keep `PROJECT_CONTEXT.md` current when meaningful behavior, integrations, or
operational setup changes. Never record passwords, encryption keys, SMTP secrets,
student data, or contents of the local database in project documentation.
